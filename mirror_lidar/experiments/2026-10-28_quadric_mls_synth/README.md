# quadric_mls 合成测试（2026-10-28）

代码：`mirror_lidar/tools/quadric_mls.py`（局部代数二次曲面 MLS，κ1−κ2 高斯先验 τ，β=0.002，μ=1），
`mirror_lidar/tools/quadric_mls_synth.py`（仿 TH-S02：16 位姿、0.47°/zone、沿射线噪声 σ）。
`main/`：默认参数（σ 用球面拟合残差 MAD 估计，refine 1 次，无离群点）。表：`main/table.txt`（`python qm_table.py main/results.json`）。
内部 = 离边界 >15 cm，镜边 = <5 cm。

结论：
- 镜面内部：误差由噪声主导，约 ∝ 1/h。平面/球面数据上 quad τ=1~3 与 plane/sphere 模型差 ≤0.03°，即确实退化；
  圆柱、抛物面上 h=0.4 时 quad 明显更好（r=0.5 圆柱 σ1cm：0.37° vs sphere 0.92°）。τ=0.3 已接近球面模型（圆柱上变差）。
- 镜边（单侧邻域）：曲率参数外推方差大，free quad 最差，τ 先验只部分缓解；σ=2.5cm、h=0.2 球面镜边：
  plane 1.7°、sphere 5.0°、quad τ1 5.8°、free 10.1°。退化性质在镜边不成立 → 下一步：先在内部估计曲率场、平滑后作为镜边先验（|A−Ā|²）。
- wavy（1 cm 起伏、0.6 m 波长）：h=0.1~0.2 最好（σ1cm 1.4~1.5°），h=0.4 偏差 ~3.2°。

## 10-29 补充：Taubin 模式、c480 实测
- `taubin/`：`mode='taubin'`（min Σw f² / Σw|∇f|²，输入法线只定朝向），h 0.1/0.2/0.4，表 `taubin/table.txt`。无噪声时平面/球/圆柱都精确；
  带噪声时和 oriented（β=0.002）几乎一样，镜边略差；**噪声导致的曲率高估两者都有**（球 R1、σ2.5、h0.2：κ 1.13 / 1.22）。
- c480 真实仿真回波（σ≈2.6 cm）上直接 MLS：κ 被高估到 1.6–3.6（h 0.15），把点挪回 GT 球面再加同样噪声也一样 → 是噪声偏差，不是数据问题。
- 解决：先在镜面 (u,v) 1 cm 格子上平均回波（每格约 50 个，法向噪声 2.5 cm → 4 mm），再 MLS；外圈 3 cm 和回波数 < 中位数 1/4 的格子不进拟合
  （光斑混到镜框，回波偏到球面后 2–4 cm）。c480：镜内法线误差中位 0.24° / p95 0.9°，外 5 cm 1.0° / 2.1°，κ (1.06, 0.99)，位置 p95 1.4 mm（h 0.2，τ 0.3）。
